## 二、各区域检查结果

### 2.1 功能业务区 —— ✅ 良好

- **闭环完整**：聊天（SSE 流式 `RemoteApiChatService`）、AI 接入（OpenAI 兼容）、记忆（FTS 检索注入）、角色卡（PromptBuilder 组装）、互动（`InteractionExecutor` 多轮状态机）、会话均已落地。
- **TTS**：v1.3 尚无语音实现（`BLUEPRINT-1.0.md` 证实），当前阶段 13 规划 v1.4 落地，属正常未动工状态。
- **发现**：无阻塞问题。

### 2.2 数据持久区 —— ✅ 良好

- Room `version = 25`，实体齐全（Conversation/Message/CharacterCard/MemoryItem 等），导出 schema。
- 迁移链 v1→v25 完整，v16→v17 建 FTS4 虚拟表+触发器、v24→v25 建 `conversation_traits`。
- 迁移测试覆盖（v12→v23 旧数据穿越、v22→v23 新列默认值）。
- 备份脚本 `backup_db.ps1` 三件套导出 + SQLite header/WAL magic 校验。
- **P2 风险**：`MemorySearchDao` 用 `@RawQuery` 动态拼 FTS SQL，绕过 Room 编译期 schema 校验——已有 androidTest 迁移测试兜底，风险可控。

### 2.3 安全合规区 —— ✅ 良好（已收敛）

- **API Key 加密**：`ApiKeyCipher`（AndroidKeyStore AES-256/GCM）→ 密文入库 `api_key_enc`，兼容旧明文迁移；无明文落盘。
- **备份规则**：`allowBackup=true` 但 `data_extraction_rules`/`fullBackupContent` 均排除 API 配置 DataStore，敏感信息不进备份。
- **组件暴露**：4 个 receiver `exported=false`（T12.3 收敛）；`MainActivity exported=true`（launcher，正常）。
- **密钥硬编码**：签名从 `local.properties` 读取，无硬编码。
- **发现**：无 P0 安全项。

### 2.4 工程构建交付区 —— ✅ 良好

- `versionCode=2` / `versionName="1.3.0"`，与 CHANGELOG 对齐。
- `libs.versions.toml` 集中管理版本。
- 发布 gate G1~G6 已定义并演练过（v1.3 发布全绿）。
- **发现**：无问题。

### 2.5 文档一致区 —— ⚠️ 有问题（本次重点）

- **[P1] `docs/TTS语音方案-待专家评审.md` 严重过时**：仍列 OpenVoice、端侧三引擎（Kokoro 主 + MeloTTS + VITS）、「星野级为预留而非目标」，与当前倾向「主引擎 MeloTTS + v1.2 CosyVoice 2 + 音质分层（暂定）」矛盾。→ **本次已加「已过时」标注，指向最新计划书**。
- **[P2] `BLUEPRINT-1.0.md` TTS 定位滞后**：仍标注 TTS 为 v2.3 远期、未启动，未反映「提前立项 v1.4」的新决策。
- **[已修复] 咨询稿 / 计划书 / PLAN.md 阶段 13**：本次已对齐（主引擎倾向 MeloTTS、CosyVoice 2、音质分层、单音色，均暂定）。

### 2.6 代码质量区 —— ⚠️ 一般

- **[P1] `ChatViewModel` 超载**：核心回复生成逻辑（流式累积/取消中断/多轮 try-catch）集中于此，`项目全面审核报告-2026-08-27.md` 已列 Q1 待拆分，尚未执行。
