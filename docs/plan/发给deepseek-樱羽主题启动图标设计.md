## 二、需求：一个 Android 启动图标

### 技术约束（必须满足）

1. Android **自适应图标（Adaptive Icon）**：需要 `background`（背景层）+ `foreground`（前景层）分离。
   - 前景层安全区是 **66dp 直径圆内**，四周会被系统裁掉（不同设备裁切形状不同：圆/圆角方/泪滴等）。
   - 所以**关键图形必须集中在中央 60% 以内**，边缘要留白，否则会被裁掉。
2. 需要**矢量或高分辨率位图**，适配 mdpi→xxxhdpi 多个密度（48dp\~192dp）。
3. 同时要有**圆形版本**（部分启动器/主题会用圆形图标）。
4. 图标在**小尺寸（48dp ≈ 十几像素）下仍清晰可辨**，不能只有大图好看。

## 重新定稿方案：「水晶樱羽」

### 核心概念

> 一朵**棱面切割的水晶樱花**，花瓣由透明水晶棱面构成，边缘有极细的金色光线勾勒。花瓣之间的间隙中，飘落着**极小的光羽**。中心花蕊是一颗**珍珠**，散发着柔和的星芒。

这朵樱花不是“画出来的”，而是“从水晶中雕出来的”。它同时满足：

- **樱花** = 品牌主题，辨识度
- **羽** = 花瓣尖端的水晶棱面呈羽毛状分叉，间隙中有微型光羽
- **水晶/珍珠/星芒** = 往世乐土+爱莉希雅的质感，拉开与普通樱花图标的差距
- **浅色 75%+** = 整体仍然是淡粉+珍珠白+极浅蓝紫，柔和治愈

## 具体图形结构（SVG可落地）

### 整体画布

- 108dp × 108dp，圆心 (54,54)
- 主体水晶樱花直径 **56dp**（半径28dp），比之前的65%缩小，留出更多呼吸感
- 安全区：全部图形落在66dp圆内

### 背景层：极浅光晕底

```
radial-gradient
中心 (54,54)，半径 66dp
色标：
  0%   #FFF8FB   （珍珠白，几乎白）
  55%  #FDE8F0   （极浅珍珠粉）
  80%  #ECE4F8   （极浅紫罗兰，冷调收尾）
  100% #E0E8FA   （极浅天蓝，呼应辅助色）
```

再叠加一层**极淡的放射光纹**（往世乐土感）：\
从中心向外发散的细线，角度每 15° 一条，颜色 `#FFFFFF` 透明度 8%\~12%，线宽 0.5dp，长度从半径 20dp 到 55dp，渐隐。\
这层纹路在大尺寸下能看到，小尺寸下完全融入背景，不干扰。

### 前景主体：水晶樱花（核心）

#### 花瓣形态——棱面切割 + 羽状尖端

每片花瓣不再用圆滑贝塞尔曲线，而是**带棱面的折线+轻微弧线**：

```
<!-- 单片花瓣 path（朝正上方，中心54,54，长度约26dp） -->
<path d="M54,54
         L50,38
         L46,28
         L48,24.5
         L51,26.5
         L54,25
         L57,26.5
         L60,24.5
         L62,28
         L58,38
         Z" />
```

**结构说明：**

- 花瓣基部（54,54）到尖端（54,25）长度约 **29dp**
- 两侧外沿用两条折线 `L50,38 → L46,28` 和 `L58,38 → L62,28` 形成棱面感
- 尖端处 `L48,24.5 → L51,26.5 → L54,25 → L57,26.5 → L60,24.5` 是**三个小棱面**，形成类似水晶切割的尖端，同时暗合羽毛分叉
- 整体形状：**菱形水晶花瓣**，尖端有羽状棱面

#### 花瓣内部：棱面折射

每片花瓣内部再画 2\~3 条**切割线**（用半透明白色细线），模拟水晶折射：

```
<!-- 左切割线 -->
<line x1="54" y1="54" x2="48" y2="28" stroke="#FFFFFF" stroke-opacity="0.5" stroke-width="0.8"/>
<!-- 右切割线 -->
<line x1="54" y1="54" x2="60" y2="28" stroke="#FFFFFF" stroke-opacity="0.35" stroke-width="0.8"/>
<!-- 横切割线 -->
<line x1="46" y1="38" x2="62" y2="38" stroke="#FFFFFF" stroke-opacity="0.25" stroke-width="0.6"/>
```

#### 花瓣填充：珍珠粉水晶渐变

每片花瓣用 **linearGradient**，方向从基部到尖端：

```
色标：
  0%    #F9C5D5   （较饱和珍珠粉）
  45%   #FDE0E8   （浅珍珠粉）
  80%   #FFF5F7   （几乎白，模拟水晶高光区）
  100%  #FFFFFF   （尖端纯白，折射感）
```

#### 花瓣描边：极细金线

每片花瓣外轮廓加 **0.6\~0.8dp 的金色描边**：

```
stroke: #D4B896 （柔和香槟金，不是刺眼黄金）
stroke-opacity: 0.7
```

金线在浅色底上刚好能“点亮”图形，又不会喧宾夺主。这是黄金庭院的克制用法。

### 花蕊：珍珠 + 星芒

中心放一颗**珍珠**，再叠加**四角星芒**：

星芒是爱莉希雅质感的点睛之笔，但要控制在**小而亮**，不能变成太阳。

### 间隙光羽

在五片花瓣的间隙中（角度 36°、108°、180°、252°、324°），放置**极小的光羽**：

```
<!-- 单片微型光羽（位于36°方向，距中心约24dp处） -->
```

- 光羽长度约 8\~10dp，非常小

- 在大尺寸下能看到羽毛细节，小尺寸下自然融入背景，不干扰主体

每个间隙的光羽角度不同，但形状相同，可以旋转复用。

## 高级感的关键维度

1. **棱面 > 圆滑**：水晶切割的直线棱面比圆润花瓣高级得多，且有“往世乐土”的圣堂感
2. **金线克制**：只有 0.6\~0.8dp，颜色是香槟金不是黄金，点到即止
3. **星芒小而亮**：白色细线组成，不是大块金色星星
4. **光羽在间隙**：不在花瓣上堆积元素，而是利用花瓣之间的负空间，视觉呼吸感强
5. **多层透明度**：切割线、光纹、光羽都用不同透明度的白色，形成“光在内部流动”的感觉

***

## 小尺寸表现（48dp）

- 水晶樱花的五片棱面花瓣轮廓清晰，金色细边在小尺寸下变成“微微发亮的花瓣边缘”
- 星芒和光羽几乎不可见，但珍珠花蕊和整体形状依然可辨
- 背景的放射光纹完全融入，只保留了粉→蓝的柔和渐变
- **视觉结果：一个精致的浅粉色水晶樱花，不是廉价的贴图樱花**

## Android Studio 落地步骤

### 1. 文件结构

```
res/
├── drawable/
│   ├── ic_launcher_foreground.xml   ← 将前景 SVG 转成 VectorDrawable
│   └── ic_launcher_background.xml   ← 将背景 SVG 转成 VectorDrawable
└── mipmap-anydpi-v26/
    └── ic_launcher.xml              ← Adaptive Icon 引用上面两个文件
```

### 2. `ic_launcher.xml`（Adaptive Icon 定义）

```xml
<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@drawable/ic_launcher_background"/>
    <foreground android:drawable="@drawable/ic_launcher_foreground"/>
    <monochrome android:drawable="@drawable/ic_launcher_foreground"/>
</adaptive-icon>
```

### 3. 非 v26 设备的位图导出

用 Python PIL 或在线 SVG→PNG 转换器，从 SVG 渲染以下尺寸的 PNG：

| 密度      | 图标尺寸    |
| :------ | :------ |
| mdpi    | 48×48   |
| hdpi    | 72×72   |
| xhdpi   | 96×96   |
| xxhdpi  | 144×144 |
| xxxhdpi | 192×192 |

将这些放入 `res/mipmap-{density}/` 目录。

## 小尺寸表现预测（48dp ≈ 12px）

| 元素       | 48dp 下状态           | 作用        |
| :------- | :----------------- | :-------- |
| 五片花瓣棱面轮廓 | ✅ 清晰可辨             | 主要识别依据    |
| 金色细边     | 退化为“微亮边缘”          | 增加精致感但不抢眼 |
| 花瓣切割线    | ❌ 几乎不可见            | 融入渐变      |
| 珍珠 + 星芒  | 珍珠可见，星芒退化          | 中心有暖色焦点   |
| 光羽       | ❌ 几乎不可见            | 大尺寸下的彩蛋   |
| 放射光纹     | ❌ 完全融入背景           | 仅大尺寸可见    |
| 整体效果     | **浅粉水晶樱花，有光感，不廉价** | —         |

## 如果要微调

| 想调什么     | 改哪里                                             |
| :------- | :---------------------------------------------- |
| 花瓣太尖/太钝  | 调整 `L46,28` / `L62,28` 的 y 值（越大越尖）              |
| 棱面感太强/太弱 | 增加/减少切割线数量，或调 `stroke-opacity`                  |
| 金边太明显    | 降 `stroke-opacity` 到 0.5 或 `stroke-width` 到 0.5 |
| 星芒太大     | 缩小星芒 path 的坐标范围（如 44→46，64→62）                  |
| 浅色不够     | 花瓣渐变 45% 色标从 `#FDE0E8` 改成 `#FDEDF2`             |
| 想要更梦幻    | 珍珠周围加 3\~4 个极小的白色圆点（半径 0.8，opacity 0.5）         |
