## 三、任务清单

### A 块：AI 对话效果提升

#### A1 · 好感度反哺 1v1 对话 【P0】
- **现状**：`ConversationRelationship.affinityScore`（Int）+ 分档工具已有，但只在互动中心用；1v1 聊天 prompt（`ChatPromptAssembler`）未注入用户↔当前角色的好感度。
- **需求**：新增 `buildAffinityFragment()`，注入用户与当前会话角色的好感度分档 + 数值，让 AI 口吻随亲密度自然变化。
- **依赖**：无（数据现成），挂载点=`ChatPromptAssembler`。
- **改动范围**：`ChatPromptAssembler` + `PromptBuilder`（少量）。
- **验收**：真机改好感度后，同一角色口吻可见亲密度差异（陌生↔亲密）；单测覆盖分档文本生成。

#### A2 · 实时情绪系统（自主 + 交互）【P0】
- **现状**：只有作息状态（睡/醒），无"此刻心情"。
- **需求**：新增情绪状态模型；**自主情绪**随时间/作息波动，**交互情绪**随用户言行触发（喜悦/别扭/吃醋/撒娇…）；随对话更新并注入 prompt。
- **依赖**：建议与 A1 同批做（共用 prompt 挂载点），情绪数据模型独立。
- **改动范围**：新增情绪状态模型 + 仓储 + `ChatPromptAssembler` 注入 + 更新逻辑。
- **验收**：角色会因用户言行产生情绪起伏；单测覆盖情绪触发与衰减。

#### A3 · 世界书（数据层 + 注入）【P1（已充分细化）】
- **依赖**：新增表 `world_info_book` / `world_info_entry` + `conversation.worldBookId`（Room 迁移）；注入点挂 `ChatPromptAssembler`；**UI 入口依赖 B3**。
- **改动范围**：数据层 + 迁移 + 注入 +（UI 后接）。
- **验收**：命中关键词才注入、未命中不注入；token 预算生效；单测覆盖命中/排序/预算。

#### A4 · 情感记忆 【P1】
- **需求**：区分"事实记忆"与"情感记忆"（角色对用户的情感态度），情感记忆优先注入。
- **依赖**：现有记忆底座（T5.x / T7.x）。
- **验收**：情感类记忆能稳定注入并体现于口吻。

#### A5 · 开场白 【低优先级】
- **需求**：角色开场白（确认 `CharacterCard.firstMessage` 现状后再定是否需补充）。

#### A6 · 3 人群聊（你 + 2 角色）【P1，最大工程】
- **需求**：群聊会话；同一张角色卡的不同会话角色可拉进同一群。
- **依赖**：会话/参与者模型改造，依赖较广。
- **验收**：3 人群聊可正常多轮、角色间可互动、同卡双实例并存。

### B 块：UI 导航重构

#### B1 · 底部 4 Tab 导航 【P0 / 地基】
- **需求**：微信式底部导航「角色卡 / 会话 / 互动 / 我」，默认「会话」。
- **依赖**：导航架构改造，是 B 块其余项前置。
- **改动范围**：`AppNavHost` + 各入口签名。
- **验收**：4 Tab 切换正常、返回栈正确、已验聊天链路无回归。

#### B2 · 设置页单栏折叠 【P2】
- **依赖**：B1（设置并入「我」Tab）。
- **验收**：分类折叠展开正常、不超长。

#### B3 · 角色卡页（置顶卡 + 立绘 + 网格 + 世界书入口）【P1】
- **需求**：顶部世界书入口卡；第二行置顶角色卡独占一行（立绘背景）；下方其他角色卡两两/多列网格。
- **依赖**：B1 + **新增角色卡「立绘」字段**（当前仅有 `avatar` 方形裁剪，需新增竖版大图字段 + Room 迁移）。
- **改动范围**：数据层 + 角色卡页 UI。
- **验收**：置顶卡独立一行、立绘背景显示、网格排列正确、世界书入口可达。

#### B4 · 关系图谱视图 【P1】
- **需求**（用户规格）：`我` 默认且强制开启关系图谱；点开可见与其他会话角色间的事（前提：对方也手动开启关系图谱）；开启的会话角色在 `我` 下方出现（`我` 置顶独占一行，其他角色两两一行）；点某角色可见其与其他开启角色关系。
- **依赖**：现有关系数据（`conv_relationship` + 关系事件）；需新增**会话级图谱开关字段**。
- **验收**：图谱层级/开关/两两成行符合规格。

#### B5 · 记忆页重排（先选角色再切视图）【P1】
- **需求**：记忆页先选角色，再在「列表 / 时间轴 / 关系图谱」间切视图。
- **依赖**：B1 + 现有记忆页。
- **验收**：角色筛选 → 视图切换流畅。
