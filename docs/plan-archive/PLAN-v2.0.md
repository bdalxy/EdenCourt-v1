### 阶段目标（产品形态，已对齐）
- 把现有若干会话角色拉进一个群聊；你发话后，多个角色**带各自已有亲密度/记忆/作息**自由接话；消息按**名字+头像**渲染；**同一张角色卡的不同会话角色（同卡多实例）可同群**。
- **复用节奏基础（1v1 已有）**：T5.8 动作神态气泡内小字斜体 · T5.9 拆条连发+「对方正在输入」 · T5.10 双向可打断+交错（均已真机验证）。群聊不做重复轮子，只把它抽成通用层 + 叠加多角色归属与幕约束。

### 用户三点反馈（已落地，2026-09-07 确认）

> **已落地**（2026-09-05 commit `c566cb3`，A6-1~A6-6 全完成）：原本的三点反馈已在 A6 实现中落地——①动作神态斜体行+角色可连发多条；②幕/回合约束（只有你发话开新幕 + 幕尾终止标记 + 每幕 ≤6 条硬上限）;③逐条「打字停顿」节奏层（A6-4，发一条→停顿→下一条，按长度间隔，群聊/1v1 共用）。下方原文为当时讨论底稿。
1. **动作神态 + 一个角色可连发多条**：角色一句话可带动作神态（斜体行），且一个角色一次可连发多条，像真人连发几句。
2. **约束（防止 AI 无限互接）**：多角色自由接话必须有「幕/回合」有界机制——只有你发话才开新幕；AI 在幕尾给**终止标记**；叠加**硬上限兜底（每幕 ≤ 6 条）**；停住等你开口才推进。保证 AI 永远不会自己聊到没完。
3. **逐条「打字停顿」节奏（修正 T5.9 现状）**：当前 T5.9 把拆条按顺序**一次性**发出；正确应是「发一条 → 停顿（模拟打字，短句 ~0.8s / 长句 ~1.8s + 「正在输入…」）→ 下一条」。**单条可较长，停顿在条与条之间的节拍上**。该节奏提炼为通用消息呈现层，群聊与 1v1 共用。

## 9.20 阶段 15（v2.0 · 关系引擎）：线上真人聊天 → 关系分叉养成（用户 2026-09-04 提出，方向骨架已对齐，待细化）✅ 已完成（R1/R2/R3/R4 已落地，R5 于 2026-09-07 拍板取消——方向+浓度数值均不外显）

> 方向性质：这是比「群聊 / 面对面感」更上位的**产品主轴**——核心不再是"聊天陪伴"，而是「线上真人聊天 → 情感深入 → 按情感倾向分叉成不同关系」。
> 本阶段尚未细化成原子任务点；下为已对齐的方向骨架（待用户进一步确认细节后立项）。

### 已对齐的方向骨架（候选/待确认，非定案）
1. **情境**：始终是"线上真人聊天"（用户心里知道隔屏，无需刻意演）。
2. **关系引擎两轴（第一版）**：`方向轴`（关系偏什么：朋友/同好/暧昧/恋人…，AI 自动判断、可渐变）+ `浓度轴`（亲密度数值，**双向可涨可落**，承接「平淡期/冷却」）。阶段状态机（陌生→亲密）留二版升级，不在本版。
3. **情感倾向来源**：大部分走 AI 自动判断（②）；手动指定（①）保留但降级为「角色卡可选预设字段」，低优先级、平时不用。
4. **关系性质**：是「当前关系」而非「目标结局」；感情有平淡起伏，浓度轴双向波动，不会一路冲高。
5. **面对面 / 隔屏**：降维为**呈现手段**，服务关系层，不再作为独立主线；默认营造"像真人线上聊天"的感觉。
6. **无限制基调**（见 §0）：不做内容过滤层，不主动设防/引导。

### 已定事项（2026-09-05 专家反馈 + 用户拍板）

- **浓度轴**：`affinityScore`（0~100）= A1 增长 + R2 回落（确定性规则）；方向切换**初版不联动快调浓度**（受控例外留待增强）。

- 暂留待接：群聊（§9.19）、面对面感、真人对话节奏、阶段状态机（二版）。
